# 🏗️ תוכנית־על למאגר TeshuVault

## 🎯 חזון

להפוך את מושג התשובה ממילה רחבה למפת לימוד ומעשה: נאמנה למקורות, בהירה למשתמש, רגישה לנפגעים, פרטית כברירת מחדל ויפה דיה כדי להזמין חזרה.

## 👥 קהלי יעד

1. אדם המבקש לבנות תהליך אישי.
2. חברותא המחפשת מקורות ושאלות.
3. מנחה המעביר שיעור או מעגל לימוד.
4. עורך תורני הבודק מראי מקום.
5. מפתח התורם לכלי האתר.
6. יוצר תוכן המבקש מפה חזותית אחראית.

## 💎 הצעת הערך

- **עומק:** שבע אסכולות וארבעים נקודות מבט.
- **מעשה:** צעד אחד לכל פרשנות ומסלול 12 שערים.
- **כבוד:** השבה, פרטיות וגבולות לפני חשיפה.
- **עצמאות:** אתר ללא ספריות צד שלישי.
- **המשכיות:** 120 משימות ויומן גרסאות.

7. חוזר לסקירה שבועית.

## 🛠️ ארכיטקטורה טכנית

- HTML סמנטי יחיד.
- CSS רספונסיבי עם משתני ערכה.
- JavaScript טהור.
- נתוני תוכן בקובץ מקומי.
- מרנדר Markdown מוגבל ובטוח.
- `localStorage` להתקדמות וליומן.
- Service Worker לעבודה ללא רשת.

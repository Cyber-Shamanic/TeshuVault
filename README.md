## 🕯️ הגדרת הליבה

**תשובה מלאה היא שיבה של כל האדם:** הכרה אמיתית, הפסקת המעשה המזיק, וידוי, חרטה בונה, קבלה מעשית לעתיד, תיקון הנזק, פיוס הנפגע, שינוי המידה שהולידה את הנפילה, והפיכת הכוח ששירת את החטא לכוח של אהבה, תורה וחסד.

היא איננה רגע יחיד אלא מערכת חיה:

1. **אמת** — לראות ולקרוא לדבר בשמו.
2. **עצירה** — להפסיק את הדפוס בפועל.
3. **אחריות** — להתוודות בלי להאשים אחרים.
4. **השבה** — לתקן נזק ממוני, רגשי, חברתי ורוחני.
5. **בחירה חדשה** — לבנות תגובה חלופית למבחן הבא.
6. **אהבה** — להפוך את המרחק לכיסופים ואת הכישלון לשליחות.
7. **התמדה** — לחזור ולדייק גם את התשובה עצמה.

## 🚀 הפעלה

האתר אינו משתמש בספריות צד שלישי:

```bash
python3 -m http.server 8080
```

פתחו בדפדפן:

```text
http://localhost:8080
```

האתר עובד גם בפתיחה ישירה של `index.html`. טעינת מסמכי Markdown דרך המודלים פועלת באופן מלא דרך שרת מקומי, ובפתיחה ישירה מוצג תוכן גיבוי מובנה.

## 🔎 דרך הלימוד המומלצת

1. התחילו ב־[`docs/interpretations.md`](docs/interpretations.md).
2. עברו אל [`docs/complete-path.md`](docs/complete-path.md).
3. בחרו קבלה קטנה אחת מתוך [`docs/forty-day-practice.md`](docs/forty-day-practice.md).
4. במקרה של פגיעה באדם אחר, הקדימו השבה ופיוס בהתאם להלכה ולמציאות.
5. בצעו בדיקה שבועית: **מה הופסק, מה תוקן, ומה נבנה במקום?**
